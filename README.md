# JustinyAhin/homebrew-tap

Homebrew formulas for my command-line tools.

```sh
brew install JustinyAhin/tap/<tool>
```

## Tools

- [nanaoki](https://github.com/JustinyAhin/nanaoki): stop your coding agents from repeating mistakes they already fixed.

Formulas in `Formula/` are written by each tool's release workflow. Do not edit them by hand.
